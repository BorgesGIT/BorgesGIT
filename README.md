## About

Software engineer since 2010, building and modernizing systems with Microsoft technologies across banking, payments, tax and accounting, health and telecom. Today I work on .NET 10 microservices with RabbitMQ and AWS, and in my own projects I build full products end to end with .NET, React and an AI-first workflow.

## Highlights

- Building .NET 10 microservices extracted from a monolith, with RabbitMQ, MassTransit, EF Core and Amazon Aurora
- Production data migration from multi-tenant SQL Server to Aurora with AWS DMS
- Card acquiring and receivables systems for a large bank, including settlement flows through Brazil's CIP central grid
- .NET 6 Minimal APIs for a national payments project at a central bank
- Legacy modernization: VBA and VB6 systems migrated to VB.NET and C#
